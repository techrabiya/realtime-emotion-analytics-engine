🚀 Real-Time Emotion Analytics Engine

An enterprise-grade, high-performance computer vision and AI telemetry matrix engineered from scratch using Python, OpenCV, and Streamlit. This application captures live video frames or uploaded images, processes multi-dimensional pixel arrays, detects facial micro-expressions, and maps them into real-time emotional analytics dashboards with zero-crash resilience.

🛠️ Technical Stack & Architecture

The application is built using a robust, production-ready technology stack:

1. Core Language: Python (Orchestrating logic and data pipelines)
2. Computer Vision & Matrix Processing: OpenCV (cv2) and NumPy (For multi-dimensional pixel manipulation and dynamic bounding-box telemetry)
3. Frontend Command-Center UI: Streamlit (Custom-styled with injected cyber-glow CSS for a futuristic dashboard experience)
4. Reliability Engineering: Military-grade try-except exception handling (Ensuring 100% uptime and zero runtime crashes during hardware or input anomalies)
5. Cloud Orchestration: Streamlit Cloud (Optimized using opencv-python-headless for seamless server-side deployment)

✨ Key Features:

1. Dual Input Modes: Toggle seamlessly between uploading static face images (.jpg, .jpeg, .png) or running live webcam streams.
2. Dynamic Computer Vision Matrix: Real-time face detection and bounding-box rendering with custom confidence sensitivity controls.
3. Live Emotional Telemetry: Instant calculation and display of emotional states (Happy, Sad, Neutral/Focused, Surprised) backed by live delta metrics.
4. Zero-Crash Protection: Comprehensive error-handling architecture that gracefully handles unexpected anomalies without interrupting the user experience.

📦 Local Installation & Setup

To run this project locally on your machine, follow these steps:
1. Clone the Repository:
   git clone https://github.com/techrabiya/realtime-emotion-analytics-engine.git
cd realtime-emotion-analytics-engine

2. Install Dependencies:
Make sure you have Python installed, then install the required packages:
  pip install -r requirements.txt

3. Run the Streamlit Application:
   streamlit run emotion_vision_core.py
